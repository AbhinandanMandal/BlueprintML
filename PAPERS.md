## Guidelines

Following are the list of implemented papers to far. Contributors are welcome to implement papers from different domain and topics such as, **Advanced Machine Learning**, **Artificial Intelligence**, **Reinforcement Learning**, **Computer Vision**, **Natural Language Processing** etc. 

Contributors are requested to make table for each domain with **method/family**, **original paper link** and **implemented code link** as specified into **Self-Supervised Learning**.
> Additionally, contributors can add a small scale report for the following implementation
